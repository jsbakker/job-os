(Toronto, ON, Canada)
June 2022 - June 2026

### Key Skills
TypeScript, Java, Spring Boot, Angular, NgRx, Hibernate, PostgreSQL, OAuth2, REST, Redis, AWS, Docker, GitHub Actions, JUnit, Jest, Agile/Scrum

### Highlights
• Led the migration of a monolithic dispatch system to Spring Boot microservices across 6 core domains (dispatch, billing, fleet tracking, customer accounts, notifications, reporting), improving deployment independence and fault isolation.
• Built the fleet-tracking dashboard in Angular with NgRx for state management and RxJS-driven live updates, replacing a polling-based UI that dispatchers had complained about for over a year.
• Refactored Hibernate criteria queries and redesigned PostgreSQL indexes on the dispatch-assignment tables, cutting the slowest endpoint's response time from ~3.5s to under 500ms under peak load.
• Implemented Spring Security with OAuth2 and JWT across all customer-facing REST endpoints, replacing a legacy API-key scheme and adding role-based access control for dispatcher, admin, and customer roles.
• Containerized all services with Docker and wrote the team's first GitHub Actions CI pipeline, cutting new-developer environment setup from a full day to under an hour.
• Introduced JUnit and Jest test suites to the previously untested billing service, and helped move the team from ad hoc task-tracking to a two-week Scrum cadence with regular retros.
